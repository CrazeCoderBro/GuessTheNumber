# Guess the Number Game

A fun browser-based game where players guess a randomly generated number.  
Built with **HTML, CSS, and JavaScript**, this game features **5 difficulty modes** and keeps track of attempts.  

## Game Modes
1. **Beginner:** 1 – 100 (with progressive range hints)  
2. **Easy:** 1 – 1,000  
3. **Medium:** 1 – 10,000  
4. **Hard:** 1 – 100,000  
5. **Expert:** 1 – 1,000,000  

> Lower modes give hints to help beginners, higher modes are more challenging.

## Features
- Tracks number of attempts for each game.  
- Provides feedback: Too low / Too high.  
- Progressive difficulty for fun leveling.  
- Works directly in your browser (no installation needed).  

## How to Play
1. Open `index.html` in your browser.  
2. Choose a difficulty mode.  
3. Enter your guess and click “Guess”.  
4. Keep guessing until you find the correct number.  
5. Check your attempt count and try to improve your score!  

## Hosting Online
- Can be hosted for free on **GitHub Pages, Netlify, or Vercel**.  
- Can also be embedded into **Google Sites** via URL.
